# Demo Data

This folder contains synthetic demo datasets generated from the private research pipeline.

Files:
- `demo_daily_clean.csv`: synthetic processed dataset for public EDA / modeling demos
- `demo_TRD_Dalyr.csv`: synthetic raw-style dataset for public cleaning-pipeline demos

Notes:
- These files are synthetic and do not correspond to real securities or real transactions.
- They preserve public demo usability only.
- Private original datasets are not included in this repository.
